02 • Mathematics

Modular Arithmetic

Each letter is mapped to an index from 0 to 25 ($A=0, B=1, \dots, Z=25$). The transformation wraps around using modulo 26.

Encryption: C = (P + K) mod 26
Decryption: P = (C − K + 26) mod 26

Non-alphabetic characters (spaces, numbers, punctuation) pass through unmodified.

04 • Cybersecurity

Cryptographic Analysis

Why Caesar Cipher is historically foundational yet practically vulnerable:

  • Symmetric Encryption: The sender and receiver must both know and use the identical key $K$.
  • Small Key Space: Only 25 possible shifts. A modern computer tests all keys in less than 1 millisecond.
  • Frequency Analysis: Common letters (like 'E' and 'T') preserve their statistical frequency, making it easy to crack.
